# Ávora Assessoria

Landing page responsiva criada como demonstração de captação de leads. A interface reúne um formulário com validação dos campos e mensagens visuais de confirmação.

## Funcionalidades

- Layout responsivo para computador e celular.
- Validação de nome, telefone e e-mail.
- Máscara automática para telefone.
- Campo opcional de observação com contador.
- Feedback visual de preenchimento.
- Formulário demonstrativo sem envio de dados.

## Tecnologias

- HTML
- CSS
- JavaScript

## Como usar

### 1. Clone o repositório

```bash
git clone https://github.com/guilhermejan/avora-assessoria.git
cd avora-assessoria
```

### 2. Abra o projeto

Você pode abrir o arquivo `index.html` diretamente no navegador ou executar a pasta com a extensão **Live Server** do VS Code.

Nenhuma instalação de dependências é necessária.

## Estrutura

```text
avora-assessoria/
├── index.html
└── README.md
```

Os estilos e o JavaScript estão incluídos no próprio `index.html`.
